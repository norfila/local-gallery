# Changelog

## [0.23.0] - 2026-11-22

### Added
- Choose the app language in Settings (English, Deutsch or the phone's language); on Android 13 and newer it also appears in Android's per-app language setting.
- Light, Dark and System shown as small pictures of the library.
- Ten color palettes, including the phone's wallpaper colors (Android 12 and newer); Sage stays the default.
- Pure black background for dark mode.
- Website and source code links in Settings; About says the app is open source.
- The full version is published as a signed APK on GitHub Releases.

### Changed
- Photo and folder layout are set on their pages (the button beside the item count) and no longer in Settings.
- Language and Start page open their list wherever the row is tapped.

### Fixed
- Highlighted entries (the current choice in menus, selected rows) stay readable with every palette, including wallpaper colors that make highlights light in dark mode.

## [0.22.0] - 2026-11-21

First public release of the source code.
